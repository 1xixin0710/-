# 大数据分析原理与实践 · 课程助教

面向**商学院同学**的大数据分析课程学习网站，以王宏志《大数据分析原理与实践》（机械工业出版社）的知识体系为骨架组织内容。

纯静态站点：无需安装、无需联网、无需后端，所有学习记录保存在浏览器本地。

---

## 十三大功能模块

### 学
| 模块 | 说明 |
|---|---|
| 知识思维导图 | 全书总图，可折叠 / 缩放 / 拖动，支持导出 PNG 图片与 Markdown 大纲 |
| 章节精讲 | 13 章，每章含学习目标、核心内容、核心概念、易错点、商学视角、常用工具 |

### 练
| 模块 | 说明 |
|---|---|

## 使用方法

### 方式一：直接打开
双击 `index.html` 即可。部分浏览器在 `file://` 协议下会禁用本地存储，此时学习记录不会保留。

### 方式二：本地服务器（推荐）
需要 Python 3：

```powershell
python -m http.server 8899 --directory .
```

然后浏览器访问 <http://127.0.0.1:8899>。

### 方式三：在线访问
若已部署到 GitHub Pages，直接访问仓库对应的 Pages 地址即可。

## 说明

- 内容依据《大数据分析原理与实践》的知识体系整理，**各校课程大纲与教材章节顺序可能不同**，如需对齐请调整 `assets/data/chapters*.js` 中的章节顺序与标题。
- 学习数据（进度、错题、笔记）全部存储在本机浏览器 `localStorage` 中，**不会上传到任何服务器**，可在「学习进度」页导出为 JSON 备份。
- 题库中的计算题均给出完整解题步骤与易错提示，适合作为期末复习使用。
